# Workout Planner

An AI-powered workout planner that generates personalized strength training routines based on a user's fitness goals and available equipment.

> **🚧 Work in Progress**
>
> This project was built as part of my journey learning React and TypeScript. It is actively being improved as I continue strengthening my React skills, increasing TypeScript type safety, and refactoring components for better maintainability and scalability.

## Live Demo

🔗 (https://workout-planner-six-lilac.vercel.app/)

## Features

- 🤖 Generate personalized workout plans using AI
- 💪 Select multiple fitness goals
- 🏋️ Choose available equipment
- 📱 Responsive design for desktop and mobile
- 🌙 Light and dark mode support
- ⚡ Loading, error, and empty states for a polished user experience

## Tech Stack

- React
- TypeScript _(ongoing adoption and improvements)_
- Vite
- Tailwind CSS
- Google Gemini API _(planned migration to the OpenAI API)_

## Getting Started

### Clone the repository

```bash
git clone https://github.com/ashlee-seagle/workout-planner.git
cd workout-planner
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file in the project root.

```env
VITE_GEMINI_API_KEY=your_api_key_here
```

### Start the development server

```bash
npm run dev
```
